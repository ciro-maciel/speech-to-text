# Security

Speech to Text listens to the microphone, pastes into other apps through the Accessibility permission, keeps a text history on disk and can hold an OpenRouter API key (in the Keychain). A bug in any of these can expose what someone said or typed, so please report it privately.

**How:** open a [private security advisory](https://github.com/ciro-maciel/speech-to-text/security/advisories/new) on this repository. Please don't open a public issue for it.

**What helps:** the macOS version, the app version (menu bar icon, then the settings window), the steps, and what was exposed or sent where.

You will get an answer within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.

Supported: the latest release only.
